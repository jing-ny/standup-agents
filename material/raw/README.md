# raw/

Verbatim dumps. Append-only. **The AI never edits anything in this directory.**

One file per dump: `<date>-<two-word-slug>.md` with `date` and `source`
frontmatter (voice-memo / typed-rant / post-mic-notes / shower-thought). Typos
stay. Tangents stay. The ugly first phrasing often turns out to be the funny one —
that's why nothing here gets "cleaned up."

`_example-*` files are synthetic walkthrough material — delete them when you
start your own vault.
