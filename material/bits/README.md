# bits/

One file per joke, built from a raw dump. The performer's words are unmarked;
AI scaffolding is `🤖`-marked and disappears as it gets answered or rejected.

Frontmatter contract: `status` (idea / working / stage-ready / retired),
`strength` (null until performed, then S / A / B), `tested_in` (one entry per
performance). Panel verdicts append to `## History` — never overwrite old ones;
the disagreements between verdicts and stage results become your personal gates
(tutorial 03).

`_example-allen-key.md` walks the full lifecycle including a worked panel
verdict. Delete it when you start your own vault.
